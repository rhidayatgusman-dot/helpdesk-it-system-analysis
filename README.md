# Sistem Helpdesk IT Perusahaan

**System Analysis & IT Helpdesk Management System**

## 1. Tentang Proyek

Sistem Helpdesk IT merupakan proyek analisis dan pengembangan sistem informasi untuk membantu perusahaan mengelola laporan kendala teknologi informasi dari karyawan secara terstruktur.

Proyek ini dirancang untuk mengatasi permasalahan pelaporan gangguan IT yang tidak terorganisasi, kesulitan menentukan prioritas penanganan, kurangnya informasi status penyelesaian, serta keterlambatan koordinasi antara karyawan dan tim IT.

## 2. Latar Belakang

Proses pelaporan kendala IT yang hanya mengandalkan komunikasi informal seperti WhatsApp berpotensi menyebabkan laporan terlewat, informasi tidak terdokumentasi, dan kesulitan memantau progres penanganan.

Sistem ini dirancang sebagai solusi terpusat agar setiap laporan dapat dicatat, dikategorikan, diprioritaskan, ditugaskan, dan dipantau hingga selesai.

## 3. Tujuan Sistem

- Memusatkan pelaporan permasalahan IT.
- Membantu menentukan prioritas berdasarkan dampak dan urgensi.
- Mempermudah penugasan kepada staf IT.
- Memberikan informasi status penanganan kepada pelapor.
- Menyediakan riwayat aktivitas dan laporan penanganan.
- Membantu Manajer IT melakukan pemantauan pekerjaan.

## 4. Pengguna Sistem

- **Administrator:** mengelola data dan konfigurasi sistem.
- **Karyawan:** membuat laporan dan memantau status.
- **Staf IT:** menerima penugasan dan menangani laporan.
- **Manajer IT:** memantau kinerja dan melakukan pengawasan penanganan.

## 5. Fitur yang Direncanakan

- Autentikasi dan hak akses berdasarkan peran.
- Pembuatan laporan kendala IT.
- Kategori dan prioritas laporan.
- Rekomendasi penugasan staf IT.
- Pengelolaan status laporan.
- Riwayat aktivitas tiket.
- Lampiran pendukung laporan.
- Pemantauan dan dashboard Manajer IT.
- Mekanisme penyelesaian dan penutupan tiket.

## 6. Alur Penanganan

Baru → Ditugaskan → Sedang Diproses → Menunggu → Selesai.

## 7. Teknologi

- Backend: Laravel
- Bahasa pemrograman: PHP
- Database: MySQL
- Frontend: HTML, CSS, JavaScript, dan teknologi pendukung Laravel.

## 8. Dokumentasi Analisis Sistem

Dokumentasi proyek akan mencakup:

- Business Requirement Document (BRD)
- Software Requirement Specification (SRS)
- Use Case Diagram
- Activity Diagram
- Entity Relationship Diagram (ERD)
- Database Design
- SQL Query
- Test Case dan User Acceptance Testing (UAT)

## 9. Status Proyek

Proyek ini dikembangkan secara bertahap, dimulai dari analisis kebutuhan bisnis, perancangan sistem, desain basis data, implementasi aplikasi, hingga pengujian.

**Catatan:** Fitur dan dokumentasi akan diperbarui sesuai hasil pengembangan aktual.
